# 🏗️  HSE Safety & Project Portal

A web-based **Health, Safety & Environment (HSE) and Project Management Portal** designed to support construction project operations, safety inspections, reporting and supervision.


## 📌 Project Overview

The  HSE Safety & Project Portal is an Angular-based web application developed to help manage construction project safety activities and provide an organized digital platform for project supervision and HSE operations.

## ✨ Key Features

- **HSE Management** – Digital platform for managing health, safety and environmental activities.
- **Safety Inspections** – Inspection-related management and monitoring.
- **Supervisor Portal** – Dedicated interface for supervisors.
- **Project Management** – Organized project-related information.
- **Responsive Design** – User-friendly interface for desktop and mobile devices.

## 🛠️ Technologies Used

- Angular
- TypeScript
- HTML5
- CSS3
- Tailwind CSS
- JavaScript
- Git & GitHub

## 💻 Run Locally

### Prerequisites

- Node.js
- npm
- Angular CLI

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   ng serve
   ```

5. Open your browser:

   ```text
   http://localhost:4200
   ```
